# Blub app

This directory contains the website, shared API, database migrations, and Cloudflare Worker build.

Start with the [repository README](../README.md) for the product rundown, local setup, authentication behavior, database migrations, validation, troubleshooting, and contribution workflow.

Run npm commands from this directory. After the first build and local database initialization described in that guide:

```sh
npm run dev
```

The homepage is `/`; the app is `/feed`.
